# My agent: Smart Pantry Recipe Concierge

One-liner: A conversational agent that helps home cooks discover recipes and manage their pantry with a catalog of ingredients and recipes.

Tool coverage:
- Memory: Remembers dietary preferences, allergies, and current pantry inventory across sessions.
- Tools: Looks up recipe recommendations from a recipe database and checks ingredient availability.
- Catalog/UI: Recipe cards showing ingredients, preparation time, and step-by-step instructions.
- Image gen: Generates visual previews of completed dishes.
- Sandbox: Computes nutritional scaling and unit conversions for serving sizes.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: Code sandbox for recipe scaling calculations
